## Linux и Wayland

- Добавлена автоматическая вставка текста на Wayland через wtype, ydotool или dotool.
- Добавлены команды для горячих клавиш рабочего стола: начало и остановка записи, удержание для записи и отмена.
- Добавлено отключение системного звука на время записи в Linux.
- Улучшены индикатор записи и совместимость запуска с видеокартами NVIDIA.

## Исправления

- Добавлено переключение на микрофон по умолчанию, если выбранное устройство недоступно.
- Исправлены статус регистрации горячей клавиши, загрузка и сохранение настроек Linux.
- Исправлены восстановление звука после смены устройства вывода и восстановление буфера обмена при ошибке вставки текста.

Поддержка Linux остаётся экспериментальной. Для горячих клавиш и автоматической вставки на Wayland нужны дополнительные системные инструменты и настройка. Подробнее — в [инструкции для Linux](https://github.com/AKDworks/Vokeyra/blob/v0.3.3/docs/LINUX.md).
