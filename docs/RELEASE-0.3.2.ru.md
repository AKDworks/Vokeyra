## Исправления

- На Linux в разделе **«История»** теперь видны элементы управления **«Начать запись»**.
- Недоступные в Wayland настройки отключаются сразу при открытии приложения.
- Подсказки для Wayland указывают, где запускать запись.

В Wayland запись запускается через **«История» → «Начать запись»**. Глобальные горячие клавиши и автоматическая вставка текста пока не поддерживаются. Поддержка Linux остаётся экспериментальной.
