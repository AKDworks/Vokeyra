# Подготовка Vokeyra 0.3.0

Следующий целевой публичный выпуск — 0.3.0. Коммиты, отправка на GitHub и публикация релиза выполняются только по отдельной команде владельца. Профили приложений отложены.

## Порядок

1. Добавить и проверить пять моделей: Vosk Small Russian, Zipformer GigaSpeech English, Moonshine Base English, SenseVoice Small, Distil-Whisper Large v3. Сохранить максимум пять рекомендаций; веса скачиваются отдельно от установщика.
2. Подготовить Linux x64: сборку, микрофон, горячие клавиши, вставку текста, трей, автозапуск и обновления. Проверить работу в настоящей Linux-среде, отдельно X11 и Wayland. Форматы для первого выпуска: `.deb` и `.AppImage`, если оба пройдут проверку.
3. Подготовить заявку в SignPath Foundation и проверяемую сборку из исходников в GitHub Actions. Начать процесс до финального релиза; рассмотрение заявки может идти параллельно с разработкой. Заявку и контактные данные согласовать с владельцем перед отправкой.
4. После одобрения настроить Windows Authenticode для собственных EXE и установщика. Подписать внутренние файлы до упаковки, установщик — после упаковки. Затем сформировать подпись Tauri updater и `latest.json` для окончательного установщика: последующее изменение файла нарушит проверку обновления.
5. Проверить обновление установленной версии, сохранение настроек и моделей, Linux-пакеты и Windows-подписи. Обновить номера версии во всех манифестах и подготовить английские release notes. По команде владельца сделать коммит и опубликовать 0.3.0.

## Что потребуется для SignPath

- Публичный исходный код и уже доступный выпуск в распространяемом формате. Если сервису понадобится публичная сборка новой оболочки, отдельно согласовать предварительный выпуск; финальную 0.3.0 ради заявки публиковать не требуется.
- Описание функций, правила подписи и политика конфиденциальности в репозитории; не заявлять о полученной подписи до фактического одобрения.
- Двухфакторная аутентификация и назначенный ответственный за одобрение каждой подписи.
- Воспроизводимый для проверки путь от исходников и зависимостей до артефактов CI. Сторонние бинарные компоненты учитываются отдельно от собственных файлов.

SignPath Foundation предоставляет бесплатную подпись подходящим открытым проектам, но принятие заявки не гарантируется. В качестве издателя сертификата выступает SignPath Foundation; автором Vokeyra остаётся AKDworks.

Windows Authenticode и подпись обновлений Tauri — разные механизмы. Действительная Authenticode-подпись сама по себе не гарантирует немедленного отсутствия предупреждений SmartScreen: Windows также учитывает репутацию файла и издателя.

Источники: [условия SignPath Foundation](https://signpath.org/terms.html), [SignPath Foundation](https://signpath.org/), [Microsoft: репутация SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).
