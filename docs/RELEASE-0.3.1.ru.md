# Vokeyra 0.3.1

## Что нового

- **Windows x64:** добавлен установщик MSI в дополнение к EXE.
- **Linux x64:** добавлен пакет RPM для Fedora.
- Обновления приложения используют тот же формат пакета, который выбран при установке.

## Примечания

Поддержка RPM экспериментальная: проверка на реальном Linux пока не проводилась. Установщики Windows пока не имеют цифровой подписи издателя.
