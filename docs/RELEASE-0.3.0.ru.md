# Vokeyra 0.3.0

Черновик для согласования. Linux-пакеты прошли автоматическую проверку установки/запуска, интерфейса, записи с виртуального микрофона и распознавания на Ubuntu 22.04 X11. Физические устройства и нативный Wayland пока не проверены; поддержка Linux экспериментальная. Установщик Windows пока не имеет Authenticode-подписи.

---

## Что нового

- Переход с Electron на Tauri: новая основа приложения и более компактная упаковка. Распознавание по-прежнему работает локально.
- Пять новых моделей: Vosk Small Russian, Zipformer GigaSpeech English, Moonshine Base English, SenseVoice Small и Distil-Whisper Large v3. Всего доступно 19 моделей.
- Экспериментальная поддержка Linux x64: пакеты `.deb` и `.AppImage`. В X11 доступны горячие клавиши и автоматическая вставка. Для Wayland предусмотрены запись кнопкой и ручная вставка из буфера; проверка на нативном рабочем столе Wayland ещё не проведена.
- Автоматическое скачивание и установка обновлений из приложения.
- Автозамены слов и фраз для всех моделей.
- Сброс настроек, очистка истории и удаление скачанных моделей с подтверждением.
- Автозапуск по умолчанию при первой установке.

## Улучшения и исправления

- Исправлены назначение горячей клавиши и преждевременная остановка записи при удержании.
- Добавлены повторный запрос доступа к микрофону и переход к настройкам Windows после блокировки.
- Индикатор записи плавнее реагирует на голос, в том числе на тихую речь.
- Расширено удаление междометий и разговорных вставок, включая «а-а», «э-э» и «ммм».

## Обновление

При переходе с 0.1.1 установите 0.3.0 вручную. Последующие обновления можно скачивать и устанавливать из приложения.
